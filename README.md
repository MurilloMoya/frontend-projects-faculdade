# frontend-projects-faculdade


Este repositório reúne projetos e exercícios desenvolvidos durante o curso de  
**Sistemas de Informação**, com foco em **lógica de programação**, **JavaScript**  
e **manipulação do DOM**.

Os projetos foram criados como parte das atividades acadêmicas, com o objetivo  
de praticar conceitos fundamentais usados no desenvolvimento front-end.

---

## 📌 Projetos

### 🔹 Cotação de Plano de Saúde
- Formulário com regras de negócio  
- Cálculo de valores  
- Manipulação do DOM  
- Simulação de sistema real  

### 🔹 Sistema de Criação de Conta
- Cadastro via formulário  
- Validações de dados  
- Inserção dinâmica em tabela  
- Formatação de datas  

### 🔹 Lista de Carros
- Array de objetos  
- Renderização dinâmica de cards  
- Importação de módulos  
- Formatação de valores monetários  

### 🔹 Lista de Operadoras (SP / RJ)
- Filtros com JavaScript  
- Contadores  
- Renderização dinâmica  

### 🔹 Motos Elétricas
- Entrada e validação de dados  
- Cálculos práticos  
- Organização de código  

### 🔹 Cálculo de Painéis Solares
- Lógica matemática  
- Formulário funcional  
- Manipulação do DOM  

---

## 🎓 Contexto Acadêmico
Todos os projetos foram desenvolvidos como **exercícios acadêmicos** durante a  
graduação em **Sistemas de Informação**, com foco no aprendizado prático de  
programação e lógica.

---

## 🎨 Observação
Os projetos foram desenvolvidos **durante as aulas**, com orientação do professor.  
A estrutura visual, arquivos de **CSS**, layouts e imagens iniciais foram  
**fornecidos como base**, enquanto a **lógica em JavaScript**, cálculos, validações  
e manipulação do DOM foram implementados pelo aluno.

---

- HTML5
